# Typewriter - Forward-Only Micro-Drafting Studio

A forward-only, distraction-free writing environment designed to cure editing paralysis. By separating the act of drafting from the act of committing, **Typewriter** forces you to move forward, one thought at a time.

## 🖋️ The Philosophy

Traditional word processors allow endless back-editing, which can trap writers in a cycle of perfectionism. Typewriter changes this dynamic:
1. **Draft:** You write your current thought in a temporary, character-limited buffer.
2. **Commit:** Once committed, the text is permanently pressed onto the "ink" page. 
3. **Move Forward:** You cannot go back and edit the ink stream on the fly. You can only move forward.

## ✨ Features

- **Forward-Only Mechanics:** Draft in a focused buffer and commit to the page. Once it's in ink, you keep moving.
- **Typewriter Physics:** Authentic scrolling behavior and keyboard sound feedback to emulate the tactile feel of a physical typewriter.
- **Page Limits:** Set custom word counts per page to break your writing sessions into manageable chunks.
- **Offline-First & PWA:** Install it directly to your desktop or mobile device. Works completely offline.
- **Export & Sync:** Export your manuscripts to `.md` or `.txt`, or sync directly to Google Drive.
- **Customizable Themes:** Includes classic Light, Dark, and high-contrast "Matrix" visual themes.
- **Complete Formatting Freedom:** The drafting buffer respects exact whitespace, meaning you have total artistic control over text gaps, run-on words, and formatting.

## 🚀 Getting Started

This is a lightweight application served via Node.js.

### Prerequisites
- [Node.js](https://nodejs.org/)

### Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the local server.
4. Open your browser to `http://localhost:3000`.

## 🛠️ Built With
- HTML5 / CSS3 / Vanilla JavaScript
- Node.js (Static file serving)
- Google Drive API integration
